# Hello World: A Japanese Garden in ASCII

A simple Python project that starts with:

```python
print("Hello, World!")
```

and then renders a small Japanese-inspired ASCII garden directly in the terminal.

This project combines basic Python output with text-based ASCII art and a quiet Japanese aesthetic.

## About

This project is a small experiment in combining:

- Python
- Terminal output
- ASCII art
- Japanese garden aesthetics
- Minimal digital art

The idea is simple:

> Code does not always have to solve a problem.  
> Sometimes code can create a small moment of calm.

---

## Meaning of 一期一会

**一期一会 — Ichigo Ichie**

A Japanese expression often translated as:

> One time, one meeting.

It reflects the idea that each encounter is unique and may never happen in exactly the same way again.

That idea fits this small terminal garden: a temporary scene appearing on the screen and experienced for a moment.

## How It Works

The ASCII artwork is stored inside Python multiline strings using triple quotes:

```python
text = '''
ASCII ART
'''
```

Then displayed with:

```python
print(text)
```

Example:

```python
print("Hello, World!")

text = '''
Japanese Garden
'''

print(text)
```

## Why ASCII?

ASCII art turns ordinary text characters into visual forms.

Characters such as:

```text
/
\
_
|
.
^
&
~
```

can become:

- branches
- trees
- mountains
- water
- bridges
- landscapes

It is one of the simplest forms of digital art and works naturally inside a terminal.
